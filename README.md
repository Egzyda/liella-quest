# リエラクエスト

Liella!の11人が、魔王討伐の旅に出た。あなたは魔王。道中のモンスターを作って、彼女たちがどう攻略するかを見届けるゲームです（ブラウザで遊べます。スマホ縦画面対応）。

## 遊び方
1. **魔王の玉座**で「作る」→ モンスターを作る（魔力の範囲で）→「挑ませる」。
2. パーティーが**作戦会議**で出撃する4人と作戦を決め、戦います。誰が何をなぜしたか（考えごと）が見えます。
3. 勝てば次の戦いへ。負けたら町に戻って**反省会**。図鑑に書いたことを元に、作戦を変えてまた挑んできます。
4. 草原は4戦。最後はボスです。

### モンスター作り
- **能力**：体力・物理攻撃・魔法攻撃・物理防御・魔法防御・素早さ（0〜10）。数字が大きいほど魔力を多く使います（極端な数字は割高）。素早さ8以上で2回行動。
- **効き目**：剣・槍・弓・拳・6属性の魔法それぞれに「大きな弱点〜効かない」。弱点を作ると魔力が少し戻ります（最大9）。
- **特性**：再生・飛行・反射・毒・怒り・全体攻撃。
- パーティーは**見た目（形と色）**で判断します。火の色なら「水が効くはず」と思いこむので、そこを無効にしておくと引っかかります。同じ見た目で中身を変えると、前の記憶が通じず混乱します。

### パーティー
- 11人それぞれ、武器・属性・回復・歌・かばう・分析の**得意度（0〜10）**と性格（慎重・無鉄砲・試したがり・こだわり・理屈・出たがり・仲間思い）があります。
- 使った武器や魔法は少しずつ上達します。戦った人は疲れ、倒れた人は次の戦いを休みます。控えも経験値を半分もらえます。
- **図鑑**はパーティーが見て覚えたこと。会心の一撃を「弱点」と勘ちがいすることもあります。

## 作戦会議の頭脳
| モード | 内容 |
|---|---|
| ふつう | AIなし。性格と数字で考えます |
| クラウドAI | Cloudflare Workers AI が作戦会議をします（1日の無料枠あり。切れたら「ふつう」） |
| PCのAI（Ollama） | PCのAIアプリが作戦会議をします。回数制限なし。PC専用 |

セリフはどのモードでも、キャラごとに用意したものです（口調が崩れないように）。AIは出撃メンバーと作戦を選ぶだけです。

### PCのAI（Ollama）を使う
リエラ人狼・ナリユキワールドで Ollama を準備ずみなら、手順2だけでOK。
1. Ollama を入れて `ollama pull gemma3:12b`（くわしくは liella-wolf-night の README）。
2. PowerShell で、遊ぶゲームのアドレスをカンマでつないで設定し、Ollama を再起動：
   `setx OLLAMA_ORIGINS "https://liella-wolf-night.pages.dev,https://nariyuki-world.pages.dev,https://liella-quest.pages.dev"`
3. タイトルで「PCのAI（Ollama）」を選んで始める。

## 公開（Cloudflare Pages）
GitHub の main を Cloudflare Pages につなぐと自動で公開されます（ビルド不要・出力ディレクトリはそのまま）。クラウドAIを使うときは、Pages の設定 → バインディングで Workers AI（変数名 AI）を追加します。
